# 知识锁画板排版

版本：draft-0.6 · 2026-11-24。随完整工具包使用；从[主Skill](../../SKILL.md)接续，可在已有说明有效时单独执行排版修订。

## 先读什么

读取[画板样式与排版卡](../../templates/board-style.md)，其中固定颜色、形状、尺寸、文字层级、间距和布线规则是本技能的样式依据，必须应用，不自行换色或把全部节点画成等大。

读取[局部卡](../../templates/local-lock.md)的中心/外围结构、[网络卡](../../templates/network.md)的共享关系，再读取用户当前画板、[说明Skill](../knowledge-gate-explain/SKILL.md)的已加入的新内容清单与逐锁说明、提案决定记录、作者改动及本轮范围。依已有绘图方式与目标操作；目标仍未明确时交回主Skill询问。

先确认当前图稿与说明对应。如果内容变了，先同步说明；如果仅改布局且说明仍有效，无需重写全文。不靠历史截图重建当前图，不把图内旧版与新版混成一份有效设计。

沿用主Skill已确定的程序化路径和视觉检查范围；需要转为Computer Use、反复截图定位或拖拽时，先按[绘图方式与成本选择](../../references/drawing-methods.md)说明消耗并取得用户选择，同时询问是否需要替代建议。已有同范围选择不重复问。

## 排版顺序

1. **核对决定、内容与标记。**图中新增设计必须有用户采纳依据，且与实际新增清单或既有记录相符。已确认补充遗漏来源标记时补上“提案＋编号”；发现未确认内容已入图时交回主Skill及[提案Skill](../knowledge-gate-propose/SKILL.md)，不能只改前缀就继续交付。保留节点身份、关系方向和条件；长说明移到图外对应条目后再精简画面。
2. **统一节点样式。**按样式卡固定4类样式：兴趣点、知识和反馈为大节点，线索为小节点。先缩短标签，完整意思移到图外；不得通过缩小字体或把线索扩成主节点来塞内容。
3. **整理局部三角。**兴趣点居中，线索环绕；三条线索用三个角位，知识与反馈在核心外。每条所属线索直接连接中心兴趣点；线索间关系按实际用途用虚线选画，不代替中心直连。三条是推荐配置，不强制补齐；K→C、C→I、I→F及必要依赖F→K按样式卡用实线。直连标签仍须有设计依据，不能用格式要求补造因果。实际只有一两条或更多线索时保留真实数量。
4. **整理网络分区。**先按共享信息和频繁联系安排局部，再检查局部外边界间距、标题、共用主节点位置与留白。不能用一整页密集格子或来回蛇形排列代替关系组织；确有这些布局需求时仍须满足可辨认的方向和干净的跨区通道。
5. **重新布线。**先局部、后跨局部，均优先直线；先调整位置和连接点，直连仍会遮挡或造成难辨交叉时才沿空白通道折弯或外绕。不为追求直线比例牺牲阅读。分散汇入/汇出位置、错开平行线与标签。移动节点后修正全部受影响连接；坐标端点图必须同步更新端点、折点和箭头，不能假定连线自动跟随。
6. **检查最终载体。**首次或全局布局变更检查全图与各局部；局部返修检查改动区域和全部受影响连接，优先用程序化预览，修正后复查相关区域。外部写入后核对目标载体的实际结果，不以本地报告替代。若必须依赖尚未确认的反复截图/界面操作，先询问；未检查的部分明确标注未验证，不宣布排版通过。

保留当前有效设计和用户手改。优先调整同一目标中的本轮内容；不擅自删旧区、复制整份网络、改用别的画板或重绘成不可编辑大图片。需要超出既有授权的操作时只提出具体需求；既有授权内的正常移动、尺寸与样式修订直接完成。

## 通过条件与交回

按工作流第2.2节检查K→C→I：发现K→I/K→F捷径、C缺前置或用换名节点补来源时交回主Skill核查，不能由排版自行添K。同时核对同一K的多处用途、多个I到同一F的行动标注，以及F→后锁K的分支/汇合。不能把不同F合成一个共建F，或把K标成另一种“形成知识”节点。未知占位保留明确文字，不通过隐藏或改色让它看似已解决。

- 视觉上先看到大兴趣点、知识和反馈，再看到外围小线索；三角结构清楚。
- 图上只保留短语、必要关系/条件、提案来源标记和紧凑图例；已加入的新内容清单与亲历说明留在图外。
- 各锁有清晰边界和间距，共享内容仍是同一内容；跨区连线可追踪，不穿过无关对象。
- 所属线索均直接连接中心兴趣点，线索间关系有实际用途；折弯用于具体避让，没有无必要绕行。
- 文字在实际形状内可读，箭头指向正确对象，没有明显遮挡、截断或含混交叉。
- 提案标记、确认记录、实际新增清单及说明一致，未确认方案没有混入；排版没有改变设计，最终实际预览已经查看。

交回主Skill前，核对最终图与说明的编号、名称、关系及版本；缩短或调整标签后让说明Skill同步受影响引用，纯位置调整可沿用说明。交回当前图稿及版本、说明入口、做过的排版修订、实际查看范围及仍存在的载体限制。无法获取实际预览时写“视觉检查未完成”，不要宣布排版合格。发现关系本身矛盾则返回设计步骤，不以改变连线含义来美化图。
